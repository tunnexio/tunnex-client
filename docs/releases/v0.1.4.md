# Tunnex Desktop v0.1.4

Release includes merged client PR #6 (345a098): managed relay connection and
bounded recovery. Both desktop manifests are 0.1.4. No new transport behavior
is introduced by this version bump.

A configured CP relay and a compatible gateway are required. Relay supports
split tunnel; full-tunnel relay remains unsupported. Direct connectivity is
preferred. Infrastructure packet tests do not establish native desktop fallback.

User authorized publication for installation and a follow-up live relay walk.
Use the existing tag workflow to build both installers and SHA256SUMS; do not
publish partial platform assets. Existing signing configuration is unchanged.
The installed user's forced-UDP-block relay/application test remains pending.
